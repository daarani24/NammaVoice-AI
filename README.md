# 🏛️ NammaVoice AI

> **Every Citizen's Voice Matters**

## Overview

NammaVoice AI is an AI-powered civic governance platform designed to bridge the gap between citizens and government authorities by providing a transparent system for reporting, tracking, and resolving public infrastructure issues.

This project is being developed as a production-ready enterprise web application as part of a capstone project.
